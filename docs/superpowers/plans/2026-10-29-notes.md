# Notes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add standalone owner-scoped notes (Title required, Description optional, timestamps shown) with full CRUD on Django API and React UI.

**Architecture:** New `server/notes/` Django app mirroring `categories/` (model + serializer + ModelViewSet + router, owner set server-side). New `client` `features/notes/` mirroring `features/categories/` (api fn + TanStack Query hooks + `/notes` page + nav). No search, no links to other resources.

**Tech Stack:** Python 3.13, Django 6.1.2, DRF 3.18.3, Simple JWT 5.5.1, drf-spectacular 0.30.0, PostgreSQL via DATABASE_URL; React 19 + Vite + TypeScript strict, TanStack Query v5, React Router v8, shadcn/ui + Tailwind v4.

**Spec:** `docs/superpowers/specs/2026-10-29-notes-design.md`

## Global Constraints

- Auth: `JWTAuthentication` only, `IsAuthenticated` default; access 15m / refresh 1d with `ROTATE_REFRESH_TOKENS` + `BLACKLIST_AFTER_ROTATION`.
- Owner scoping: every queryset filters by `request.user`; `perform_create` sets owner server-side; never trust client `owner`/`user` fields; inaccessible object returns 404 (not 403).
- Validation: Title trimmed, required, 1–200 chars; Description optional, `blank=True default=""`, serializer cap 2000 chars; timestamps read-only.
- Errors: `201` create, `200` read/update, `204` delete, `400` validation, `401` bad/missing token, `404` absent/concealed; `5xx` never leaks tracebacks.
- DB: PostgreSQL/NeonDB only via `DATABASE_URL` (`server/.env` or env var); no SQLite fallback; multi-step writes in `transaction.atomic()`.
- Client: JWT in memory only (`features/auth/session.ts`); 401 retry-once then force login; never hand-edit `src/api/schema.d.ts` — change backend then `npm run gen:api`; money rules N/A; confirm destructive deletes; loading/empty/success/error states on every async surface.
- Docs: keep `server/schema.yml` + drf-spectacular annotations in sync with routes; `python manage.py check` must pass.

## Review Focus

- Blank title with only spaces is rejected with a `title` 400, not saved as empty.
- Title of 201 chars and description over 2000 chars are rejected with field 400s.
- Cross-user list/detail/PATCH/DELETE never leaks rows — list returns `[]`, detail returns 404.
- Anonymous GET/POST/PATCH/DELETE on `/api/notes/` returns 401.
- PATCH attempting to set `owner`, `id`, `created_at`, `updated_at` ignores or rejects without changing ownership/timestamps.

```python
def test_anonymous_401_on_all_five_routes(self):
    self.client.credentials()

    from django.contrib.auth.models import User
```

```ts
import { api } from "@/api/client";
import type { Note, NoteInput, NoteUpdate } from "@/types/api";
const BASE = "/api/notes";
export const notesApi = {
  list: () => api.get<Note[]>(`${BASE}/`),
  retrieve: (id: number) => api.get<Note>(`${BASE}/${id}/`),
  create: (payload: NoteInput) => api.post<Note>(`${BASE}/`, payload),
  update: (id: number, payload: NoteUpdate) => api.patch<Note>(`${BASE}/${id}/`, payload),
  destroy: (id: number) => api.del<void>(`${BASE}/${id}/`),
};
```
